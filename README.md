# Project Description
This project aims to analyze body dimensions of myself a 26-year-old male with light exercise comparatively to active individuals within a 10-year span. First, I analyze visually through histograms and used weight to statistically confirm that I am below the average of the active male between 21 - 31 years-old.
Then a multivariate linear regression model is used to conclude that my overall body weight is not too far different from the active individuals when accounting for all the girth measurements, but there is a difference that could be due to variance or other factors such as bone / skeletal density.
